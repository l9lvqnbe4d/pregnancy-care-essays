# 北京通州友谊医院怀孕建档条件及流程攻略，附实用待产包清单

> 更新时间：2026-09-11 (UTC+8)

建档就是孕妇在医院建立一个属于自己的小册子，即怀孕档案，里面记载了孕妇的基本信息以及怀孕过程的所有信息。怀孕后，孕妇必须先去当地医院建档，然后才能在此产检、分娩。

这篇文章给孕妈们介绍的是北京通州友谊医院建档时间、建档流程、建档挂号注意事项以及建档产检花费参考。

**怀孕建档时间**

北京通州友谊医院建档数量有限，建档名额也比较紧张，一般建议孕8到9周建档。

**怀孕建档条件**

1、北京市母子健康手册

2、本院B超单(妊娠12周以前可见胎心胎芽)

3、本院艾梅乙检查单

4、孕早期心理保健评分

**注意：**

1、办理母子健康手册一般需要夫妻双方结婚证、身份证、户口本、怀孕证明(如宫内早孕B超、尿常规、血HCG化验结果等)，外地孕妈还需要提前办理电子版北京市居住证。

2、一般情况下，如果孕妇材料准备齐全且当地社区医院办理的人不是很多，基本1到2小时左右就可以办完。

**怀孕建档流程**

1、挂妇产科号，做艾梅乙检查等，预约B超，建议预约7周左右的B超。

2、到当地社区卫生服务中心领取母子健康手册。

3、按预约日期去医院做B超检查，B超检查需见胎心胎芽。

4、挂周四下午的“产科建档预约号”，携带母子健康手册、B超单、艾梅乙检查单到医院产科门诊B-3-219诊室核对孕妇信息。

5、如果孕妇符合建档条件，就可以顺利登记建档，预约产科复诊。

**建档注意事项**

1、友谊医院通州院区仅每周四下午可以挂产科号办理登记建档。

2、已经预约了产科预约建档号的孕妇，初次建档检查一定要按照预约时间到医院就诊(正式建档时间一般为周四下午13:00—15:00)。

3、空腹抽血在2楼，心电图检查在1楼，尿常规检查需要到2楼化验窗口领取尿杯。

**建档挂号渠道**

孕妇需要持相关建档资料至产科门诊进行评估，符合建档条件的孕妇可办理登记建档手续，在现场219诊室排队挂号，每周开放25个预约建档号。

**医院病房介绍**

2人间、3人间，基本都是3人间，少数2人间，2人间的床位比较紧张，床位费60元/天。

**产科服务条件**

无痛：有，2000元左右，需自费

导乐：全程八小时1500

陪产陪护：无

护工：一对一，420元/天，有时候护工数量不够，也会一对二，大概在300多元。

顺产：24小时出院;剖腹产：3到4天可出院。

**关于待产包**

必须购买医院的待产包，宝宝待产包 ，260元，产妇要求无菌的医院是必须在医院购买的。
