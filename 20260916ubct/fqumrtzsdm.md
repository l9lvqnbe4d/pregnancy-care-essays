# 北海62岁老人被银环蛇咬伤，几小时后住进ICU

> 更新时间：2026-09-16 (UTC+8)

4月26日晚22时许

北海一乡镇62岁老人干农活时

**被银环蛇咬伤右脚踝**

因当地医院缺乏抗蛇毒血清

老人被迫**连夜转院**

一场与死神赛跑的救治就此展开

**生死4小时：凌晨转运与突发恶化**

27日凌晨，老人完成出院手续后由救护车转送至市人民医院银滩院区。转院途中患者**突发呼吸困难**，医生紧急使用地米（地塞米松）对症治疗。

患者被银环蛇咬伤的右脚踝

此时距被蛇咬伤已逾4小时，患者凌晨4时许抵达急诊科后，主治医师陈文等医务人员立即开展救治，进行评估、用药，并安排抽血检查进行皮试。

在用药期间，老人生命体征平稳，然而，27日凌晨5时多，突然出现呼吸困难、烦躁不安的症状，血压也开始急剧下降，**心率最慢时仅有20多次**，血氧更是突然降低。陈文立即报告值班二线医、急诊科副主任林绍侠。

**60秒复苏对抗神经毒素！医护抢回一线生机**

面对患者突发的危急状况，由林绍侠、陈文医生及黎振秋、曾建丽、莫云等护士组成的急救团队迅速启动应急机制。在持续的心肺复苏抢救中，医护团队同步完成气管插管并启用呼吸机辅助呼吸，争分夺秒与死神赛跑。

医护团队

经过约一分钟的生死竞速，患者终于恢复自主心跳。然而危机尚未解除——因血压持续偏低且处于深度昏迷状态，医疗团队立即启动绿色通道，将患者转入重症医学科进一步治疗。

在ICU的系统性救治下，患者于4月28日恢复意识并实现自主呼吸，顺利撤除呼吸机，至29日上午病情稳定转入老年病科进行康复观察，目前病情稳定，意识清醒，已能够正常交流。

ICU病房内医生在跟患者交流

据医务人员介绍，该蛇伤病例是今年以来的**第9例蛇伤**，其中8例为竹叶青咬伤（含1例眼镜蛇毒液眼部喷溅），北海地区蛇伤多为**竹叶青**，银环蛇咬伤在北海较为少见，银环蛇咬伤主要是神经中毒致呼吸困难。

此次事件也再次提醒广大市民，在野外劳作或活动时，务必提高警惕，做好防护措施，以防遭遇毒蛇袭击。

**特别注意：**

被蛇咬伤后，应立即采取紧急措施并尽快前往医院就诊，特别是到正规有蛇伤救治条件的医疗机构。对于毒蛇咬伤最有效的方法仍然是抗蛇毒血清。目前北海市配备有抗蛇毒血清的医疗机构有：

**北海市人民医院银滩院区，地址：银海区金海岸大道69号 0779-3035121（24小时值班电话）**

**涠洲岛旅游区医院（涠洲镇中心卫生院），地址：北海市涠洲岛规划一号路以南、规划二号路以东（急诊电话0779-6012120）**

**合浦县人民医院，地址：廉州镇定海北路95号（急救中心120、急诊医学科0779-7285120）**
