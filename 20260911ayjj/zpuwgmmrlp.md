# 你们医院是我去过的最好的医院

> 更新时间：2026-09-11 (UTC+8)

“Your hospital is the best one in all the project we have made.”（你们医院是我去过的最好的医院），在我院眼科德国引智项目总结会上德国专家Gerhard Pülhorn教授如是说道。

7月12日，我院眼科引智项目总结会如期召开，德国专家Dr.Gerhard Pülhorn赴我院为期三周的学术交流、指导工作圆满结束，院党委副书记何梅、人力资源部主任胡方、医教部副主任王文英、眼科负责人及眼科骨干医务人员参与此次总结会。

唐晓蕾医生用流利的英语总结了此次引智项目成形及前期工作、实施情况、从中取得的成果和效益，其中详细陈述了项目实施中从眼科日常工作中找到有待提高的地方及改进的方法。

总结会上，Dr.Gerhard Pülhorn谈到我院的眼科医务人员的敬业程度让他很是敬佩，同时他认为我院各项流程合理，门诊、出入院秩序井井有条；把我院与许多欧洲国家医院相比也不逊色，这是他去过无数家医院中最好的医院。

何梅副书记对Dr.Gerhard Pülhorn夫妇三周的辛勤付出表示感谢。她说道，我院近两年大力开展引智项目，取得的效果尤为显著，我院正发生日新月异的变化，特别在某些疑难杂症方面提供了思路，找到了突破口；她希望进一步加深我院与Dr.Gerhard Pülhorn的合作，牢固的建立起跨国的友谊。
