# 【生殖科普】预产期怎么算最准？教你推算出最准确的末次月经

> 更新时间：2026-09-17 (UTC+8)

怀孕后第一件事，就是推算预产期。而预产期的准确计算，关键就在于确定“末次月经第一天”。很多人直接用同房或受孕日计算，其实不准确。下面就来教你几种常见情况下的正确推算方法。

**一、常规计算方法**

最常用的方法是：从末次月经第一天开始，月份减3、日期加7。

例如：末次月经是2025年9月20日 → 预产期为2026年6月27日。

注意：如果月份减3后不够（比如1月），就先加12个月再减。

例如：末次月经2025年1月20日 → 1+12=13，13-3=10月，20+7=27 → 预产期2025年10月27日。

**二、特殊情况这样算：**

1.人工授精或指导同房：

以排卵日为准，往前推14天作为“末次月经”。

例如：排卵日2025年9月20日 → 末次月经为9月6日 → 预产期2026年6月13日。

2.试管婴儿（D3胚胎移植）：

从移植日减去17天，作为末次月经。

例如：移植日2025年9月20日 → 末次月经9月3日 → 预产期2026年6月10日。

3.试管婴儿（D5囊胚移植）：

从移植日减去19天，作为末次月经。

例如：移植日2025年9月20日 → 末次月经9月1日 → 预产期2026年6月8日。

记住，无论哪种方法，最终预产期都应以早期B超检查结果为准（尤其是孕11-13周的数据），医生会根据胎儿大小进行微调。

希望这篇能帮你理清思路，轻松算出预产期，安心迎接宝宝。
